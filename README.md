# Overview
store wheel is a product catalog app built according to material 3

## stack 
- Material 3
- Hilt 
- MVVM
- Retrofit
- View binding
- Coroutines
- Nav-graph navigation

## Running 
- Either download the project and run on android studio or download the tag over your phone. 
- I've ran the project over android 10 and 16
